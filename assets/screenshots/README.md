# Screenshots / 截图

This folder should contain screenshots for the Chrome Web Store listing and the project README.

## Required Sizes / 必备尺寸

| Type | Recommended Size |
|------|-----------------|
| Store screenshot | 1280x800 or 1440x900 |
| Small promo tile | 440x280 |
| Large promo tile | 920x680 |
| Marquee promo tile | 1400x560 |

## Suggested Shots / 建议截图

1. `main.png` — Main new tab page showing bookmarks / 主界面
2. `search.png` — Search dropdown with suggestions / 搜索下拉
3. `add-bookmark.png` — Add/Edit bookmark modal / 添加书签弹窗
4. `settings.png` — Settings menu open / 设置菜单
5. `popup.png` — Toolbar popup / 工具栏弹窗

## Tips / 小贴士

- Use a clean browser profile with no other extensions visible.
- Avoid showing personal bookmarks or sensitive URLs.
- Use the default gradient background for consistency.
- Make sure text is readable at thumbnail size.
